// Pipeline
五步协作流水线
从API文档导入到报告输出，全流程自动化，无需人工干预。
01
文档解析
导入 Swagger / OpenAPI 文档，自动识别接口结构与参数定义
02
用例生成
Planner Agent 基于等价类、边界值等策略智能生成测试用例集
03
并发执行
Executor Agent 并发调度请求，自动处理鉴权与环境适配
04
智能校验
Validator Agent 对响应进行 Schema 校验与业务逻辑断言
05
报告输出
Reporter Agent 生成可视化报告，提供缺陷定位与优化建议
